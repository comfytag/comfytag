## 🚀 After Onboarding

Once you've read all 5 documents:

1. **Wait for your first task:**
   ```
   /comfytag-quality-hub BUILD "Feature name"
   ```

2. **Copy your task template** (from `AGENT_TASK_TEMPLATES.md`)

3. **Follow each step** (all checkboxes must be ✅)

4. **Post your output** when done (message in Discord/Slack)

5. **Watch it deploy** (GitHub Actions auto-handles it)

## ❓ Questions?

**Q: What if I don't understand something?**  
A: Re-read that section. If still unclear, ask your team lead or other agents in Discord.

**Q: What if I break something?**  
A: You can't — the system has safety gates. You can only commit code that passes all quality checks.

**Q: What if I'm blocked waiting for another agent?**  
A: That's normal. Check `PROJECT_CURRENT_STATUS.md` to see what's in progress.

**Q: How do I know when to start?**  
A: Quality Hub will tell you. It breaks down features into sequential tasks.
