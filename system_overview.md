## 1. Project Purpose

**ComfyTag** is a biometric-first event ticketing platform for Nigeria with the tagline *"Your Face is Your Ticket."* It enables event organizers to sell tickets to attendees aged 18–35 (Gen Z/millennials) with facial recognition-based check-in instead of traditional QR codes. Attendees enroll their face once and show it at entry; organizers verify instantly. Tickets can be transferred with automatic face sync.

**Target:** Nigerian event organizers (solo first) and attendees.

**Revenue Model:**
- 4–5% success fee per ticket (0% on free events)
- Biometric check-in premium per event
- Promoted listings for events

**Competitive Advantage:** Facial recognition integration, earnings dashboard, lower fee structure than competitors (Tix Africa 8%, Selar 4%, Syticks 3.5%).

## 4. Architecture

**Core Flow:**

1. **Authentication:** User registers/logs in via credentials → NextAuth JWT flow → API validates at `/auth/login` → token stored in JWT session
2. **Events:** Home page server-renders events (ISR 60s) from `/events` API → event detail fetches full data + performers → ticket purchase redirects to Paystack
3. **Face Biometrics:** User enrolls at `/profile/security` → KBY-AI SDK captures face → encrypted template stored in User model (never exposed) → organizer scans face at gate → FaceLog recorded
4. **Admin Controls:** Role-based access (super_admin/finance/moderator) → NextAuth + role guard middleware → admin actions audit-logged
5. **Data Persistence:** API ↔ MongoDB (Mongoose), Redis (configured, not yet integrated for caching)

## 5. Key Files

**Backend (API)**

- **`apps/api/app.js`** — Express server. Mounts all routes, configures CORS (origin whitelist), body parser (50MB), global error handler, connects to MongoDB.
- **`apps/api/models/User.js`** — User schema: auth (email, password, token), KYC (verify object), face enrollment (faceTemplate encrypted), 2FA (totpSecret, twoFactorEnabled), roles, onboarding fields.
- **`apps/api/models/Event.js`** — Event schema: name, planner, category, description, ticketType array (tiers), venue, images, status, featured flag.
- **`apps/api/models/Audience.js`** — Ticket record: event_id, user_id, amount, numOfTicket, reference (Paystack), status, faceOwner, transfer tracking.
- **`apps/api/controllers/auth.js`** — Register, login, password reset, 2FA. Uses bcryptjs, jsonwebtoken, speakeasy, Nodemailer.
- **`apps/api/routes/face.js`** — Face enrollment, verification, ticket linking. KBY-AI SDK integration (mock-first).

**Frontend (Web)**

- **`apps/web/src/app/layout.tsx`** — Root layout, fonts, global styles, Providers (NextAuth session, React Query).
- **`apps/web/src/app/page.tsx`** — Home: server-renders events + categories (ISR), mounts Navbar, HeroSection, CategoryPillsBar, EventFeedSection.
- **`apps/web/src/app/events/[slug]/page.tsx`** — Event detail: hero carousel, description, performers, ticket tiers, Mapbox map, comments.
- **`apps/web/src/lib/auth.ts`** — NextAuth config: credentials provider → `/auth/login` API, JWT/session callbacks, Google/Apple optional.
- **`apps/web/src/components/event/TicketTierSheet.tsx`** — Bottom sheet for selecting ticket tier + quantity before Paystack checkout.

**Admin Dashboard**

- **`apps/admin/src/app/(dashboard)/layout.tsx`** — Protected layout: checks NextAuth session, redirects to login if missing. Mounts ShellClient (sidebar + topbar).
- **`apps/admin/src/app/(dashboard)/overview/page.tsx`** — Dashboard: stats cards, revenue charts, top events.
- **`apps/admin/src/lib/auth.ts`** — NextAuth for admin: credentials → `/admin/auth/login`, supports OTP second factor, role-based.
- **`apps/admin/src/lib/roleGuard.ts`** — Utility to check if user has required admin role.

**Shared**

- **`packages/types/src/index.ts`** — 18 types: User, Event, Ticket, Category, Notification, FaceLog, AdminRole, etc.
- **`packages/utils/src/index.ts`** — 15 utilities: formatNaira, formatDate, slugify, calculatePlatformFee, isValidEmail, etc.
